# Research knowledge base

Place reviewed, non-sensitive research notes here as Markdown. The default
retriever is lexical and deterministic. It is intentionally not treated as
evidence: notes can inform a hypothesis, but only source/runtime artifacts can
support a confirmed finding.

For an optional Qdrant backend, preserve the metadata contract documented in
`docs/ghostbyt3-reference.md` and `src/patch2proof/retrieval.py`.
